# Portofolio Nabilah Avilia Indriyawati

Website portofolio interaktif dan responsif untuk **Nabilah Avilia Indriyawati**, lulusan S1 Sistem Informasi Universitas Siliwangi (2026).

## 🌟 Fitur
- **Desain Responsif & Estetis**: Skema warna warm pink bernuansa profesional, tipografi serif modern, dan layout adaptif untuk mobile, tablet, hingga desktop.
- **Section Lengkap**:
  - Profil & Ringkasan Diri
  - Riwayat Pendidikan (S1 Sistem Informasi UNSIL) & Pengalaman Kerja (Data Analyst Intern di Diskominfo Kota Tasikmalaya)
  - Showcase 5 Proyek Utama dengan Filter Kategori interaktif (Bisnis, Event, Pendidikan)
  - Detail Kontribusi Proyek via Modal Dialog
  - Lisensi & Sertifikasi Profesional
  - Penghargaan, Prestasi & Pengalaman Pembicara
  - Keterampilan Teknis & Kemampuan Bahasa
- **Print / PDF Friendly**: Dilengkapi tombol "Cetak / Simpan PDF" dengan stylesheet khusus cetak resume/CV.
- **Zero Runtime Dependencies**: Dibangun dengan semantic HTML5, CSS3 murni, dan Vanilla JavaScript.

## 🚀 Menjalankan Secara Lokal
Buka file `index.html` langsung di browser, atau jalankan local server:
```bash
# Menggunakan Node.js / npx serve
npx serve .

# Atau menggunakan Python
python -m http.server 3000
```
Buka browser pada `http://localhost:3000`.
